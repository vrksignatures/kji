# Third-party software in the app

The bot itself — reading the screen, pressing, the ledger, Aakriti — uses Android's own
APIs and no library. The libraries below are in the APK **for the music only**
(`MusicEngine`, `YouTubeAudio`).

These are the versions the build of 18 Nov 2026 resolved. The list for any build is in the
"What is in the APK" comment the CI posts on each pull request, and is printed by
`gradle :app:dependencies --configuration debugRuntimeClasspath`.

Size: the APK went from about 0.6 MB to about 6.8 MB with these libraries.

## What the GPL means for this app

NewPipe Extractor is licensed under the GNU General Public License, version 3 or later.
An APK that contains it is a combined work, so **whenever the APK is given to someone, the
whole app is passed on under the GPL-3.0-or-later**: the person receiving it is entitled to
the complete source code and may change and pass it on under the same licence. This
repository is that source code. If the repository is private, the source has to be offered
to whoever receives the APK.

The other licences in the table are compatible with that.

If that is not wanted, the YouTube look-up has to go: remove the `NewPipeExtractor` and
`desugar_jdk_libs_nio` lines from `app/build.gradle.kts` and `YouTubeAudio.java`. Own songs
added as direct links or files would still play.

## Not an official YouTube interface

NewPipe Extractor reads YouTube's pages and internal answers as a browser does. YouTube
does not offer this as a service, can change it without notice, and its terms of service
may not allow it. When songs stop being found, look for a newer release at
<https://github.com/TeamNewPipe/NewPipeExtractor/releases> and raise the version in
`app/build.gradle.kts`.
